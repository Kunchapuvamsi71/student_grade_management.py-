# Task 2: Core Concepts and Skills
## Student Grade Management System

A beginner-friendly Python console project demonstrating core programming concepts.

### Concepts demonstrated
- Variables and basic data types
- User input and formatted output
- Lists, dictionaries, and loops
- Conditional statements
- Functions and return values
- Input validation and `try/except` exception handling
- `sum()`, `all()`, and `zip()` built-in functions

### Requirements
- Python 3.8 or later
- No third-party packages required

### Run the project
```bash
python student_grade_management.py
```

### How it works
The program asks for a student name and marks for Python, SQL, and Computer Networks. It validates each mark, calculates the total and average, assigns a grade, and reports Pass or Fail. A student must score at least 40 in every subject to pass.

### Sample run
```text
=== Student Grade Management System ===
Enter student name: Vamsi
Enter marks for Python (0-100): 88
Enter marks for SQL (0-100): 79
Enter marks for Computer Networks (0-100): 91

=== Student Report ===
Student: Vamsi
Python: 88.0
SQL: 79.0
Computer Networks: 91.0
Total: 258.0/300
Average: 86.00%
Grade: B
Result: Pass
```
